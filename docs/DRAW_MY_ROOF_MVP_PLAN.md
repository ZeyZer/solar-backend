# Draw My Roof MVP Plan

## Purpose

The “Draw My Roof” feature is the bridge between the current simple roof input and the long-term roof geometry optimiser.

The long-term goal is:

```txt
address
→ satellite / aerial / LiDAR / surveyed geometry
→ roof planes
→ usable roof areas
→ panel placement options
→ stringing / MPPT grouping
→ inverter / battery / tariff optimisation
